First launch

Section titled “First launch”

Unpack the game into a folder of its own and run disclander.exe. The first run makes a world, which takes a few minutes and shows its progress, then opens the start menu.

From the start menu:

  • Continue picks up your newest save in this world.
  • New game starts afresh in this world, in another kept world, or in a new one. A new world can be full or half size, and 82, 102, 123 or 164 km across. Here you also choose to play a man or a woman, and a face.
  • Load game lists every save, newest first.
  • Settings holds the options and the key bindings.

The game keeps everything beside disclander.exe:

Folder or file What it holds
maps/ The worlds, one folder each
saves/ Your saves, with auto.json written as you play
settings.txt Options and key bindings
reports/ Problem reports (below)
logs/ Crash logs

Playing together

Section titled “Playing together”

Two players share one campaign. The host’s friend leads a second army on the host’s side.

  1. The host picks Co-op on the start menu, then Host a game. The game waits for a friend on port 7777.
  2. The friend picks Co-op, then Join, and types the host’s address (and port, if the host chose another).

The host’s port must be open to the friend: on the same network it usually is; over the internet the host may need to forward it. Both play the same shipped world. Only the host can load a save, and either player pausing pauses both.

Problems

Section titled “Problems”

Press F12 in the game, or pick Playtest report on the menu. It writes a folder in reports/ with your game saved, a screenshot and a note of your system. Send that folder with a line on what went wrong.

If the game crashes, it writes what happened to logs/; send that file too.
